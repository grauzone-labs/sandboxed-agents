Controls & test ideas

1. New sandbox → Image → Sandbox → Integrations (optional) → Review.
   Select an existing image or choose toolchains for a new image.
   Choose at least one agent. Skip integrations to configure them later.
   Back keeps the draft. Only Create sandbox changes the fake instance.
2. Configuration → Create token on B, then Connect remote on A: inventory stays on B.
3. Sessions → Attach: try /help or a prompt; detach and attach again.
4. Agents: enable/disable each agent. Integrations: connect/disconnect.
5. Image → Open image → Configure toolchains → Review impact.
6. Simulate error, then run an action: fake data is preserved on failure.
